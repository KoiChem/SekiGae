# SekiGae 試作版

- 通常モード: `index.html`
- サンプルモード: `sample.html`（`index.html?sample=1` に遷移し画面・処理を共有）

メイン画面の「座席数」から横4〜8列、縦4〜10行をクラスごとに設定できます。有効座席が名簿人数を下回る場合や、固定指定が範囲外になる場合は変更できません。配置済み席が消える縮小では確認後に現在配置をクリアし、名簿と確定履歴は保持します。

画面は初回の縦横に合わせ、上部の「画面」ボタンで手動切替できます。高密度表示では氏名16px以上を基本に折り返し・縦スクロールを使います。印刷は従来どおりA4縦横に収めます。

履歴復元は当時の座席数も戻します。行列数が異なる履歴は、ペア・前後・窓/廊下の経験に引き続き利用し、同じ座席・周囲8席および席追跡の盤面位置には同じ行列数の履歴だけを利用します。奇数列は教卓基準で右端が単席です。

既存版の保存データは自動読込しません。必要なクラスは既存版でバックアップを保存し、試作通常版の「バックアップ読込」で明示的に取り込んでください。取り込みは試作版内のコピーとなり、既存版には影響しません。旧データは6列×7行として扱います。

試作版で保存したバックアップはファイル名に「試作版」が入り、既存版では読み込めません。試作通常版・試作サンプル・既存版の保存領域と削除対象は分離しています。サンプルの変更は再読み込みで初期状態へ戻ります。

試作版は既存版から分離したファイルであり、既存版のHTML/JS/CSSには変更を加えていません。後の正式反映は別の作業として扱います。

## 検証

Nodeの全自動テストとPlaywrightの通常/サンプル操作で検証します。ブラウザの検証は実機のSafari・タッチ・OS印刷の確認を代替しません。端末や制約条件により探索時間・到達ポイントは変わります。
