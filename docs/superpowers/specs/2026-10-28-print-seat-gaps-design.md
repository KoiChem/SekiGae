# 印刷プレビューの座席間隔

ユーザー承認済み仕様。プレビューの行間・列間を端から端まで個別に広げ、グループの区切りを表現する。

- 教卓側端に列間、教卓から見た左側端に行間の楔形ボタンを置く。境界ごとに1 → 1.5 → 2 → 1倍。標準間隔は1mm。
- 複数境界を独立して変更できる。視点・用紙方向・空席表示が変わっても物理的に同じ境界の設定を維持する。非表示になった境界も保持する。
- ボタンは画面の操作用余白に置き、A4の印刷領域を消費しない。倍率を色と形状で識別でき、キーボードでも操作できる。隣接ボタンの操作領域は接触させない。
- 隙間を印刷・PDFに反映し、操作ボタンは印刷しない。A4一枚に収める。
- 余白で吸収できる場合は座席寸法・文字サイズを維持する。必要時のみ等寸の座席を調整し、既存の各文字のフィットを再利用する。1倍に戻すと再計算する。
- クラス単位で保存し、バックアップにも含める。古いデータは全境界1倍。新規クラスは全境界1倍。配置履歴の復元では変更しない。通常盤面・席替えルールには影響させない。
- 通常版とサンプル版を確認する。サンプルは共有画面を使い、既存サンプルJSONの未指定項目は1倍として扱う。

## 方式

既存CSS Gridに座席と隙間のトラックを交互に並べる。各隙間の合計を引いて既存の寸法計算を行う。全座席を同寸に保つため既存の文字計測を利用できる。
席ごとのmargin調整は外周・欠けた座席で整合性を取りにくいため採用しない。絶対座標への全面変更も不要。

## 実装上の判断

保存項目は `printSeatGaps: { columns: number[5], rows: number[6] }`。クラス読込時に正規化する。
プレビューの紙面外に36pxの操作余白を確保し、ボタン自体は紙面の表示倍率と独立して配置する。
既存の `guide.html` 作業中変更と未追跡のガイド成果物を今回のコミットに含めない。
