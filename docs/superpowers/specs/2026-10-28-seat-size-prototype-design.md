# 座席数可変・専用確認モーダル試作版

会話で合意済みの仕様を記録する。実装・検証・GitHub Pages公開まで承認済み。

- `prototype/index.html` / `app.js` / `styles.css` に既存版から独立した試作版を作る。`prototype/sample.html` は `index.html?sample=1` へ遷移し、画面と処理は共有する。既存版のファイルは変更しない。
- クラスごとに横4〜8列、縦4〜10行、最大80枠。メインのクラス・人数付近から座席数モーダルを開く。枠数と有効座席数を区別する。
- 拡大と、消える席に生徒がいない縮小は座標で配置・空席を保持。配置済み席が消える縮小は確認後に現在配置をクリアし、名簿・確定履歴を保持。人数不足・範囲外の固定指定は適用停止。未確定配置の破棄も確認する。増設席は有効。計算・例外選択中は変更不可。寸法変更で候補と手動Undoをクリア。
- 旧データは6×7。履歴と候補に寸法を記録。履歴復元では当時の寸法も戻す。異寸法履歴のペア・前後・窓/廊下は当時の寸法で判定して利用し、同席・周囲8席と席追跡の盤面表示は同寸法履歴のみ利用。
- 奇数列のペアは教卓基準で左から2席ずつ、右端単席。a1〜h10の指定を扱う。
- PC・タブレットの既存縦横切替を活用し、クラス・設定→生成→候補→採否の順序を保つ。ボタン間隔を確保。全体表示を基本とし、可読性や操作領域が不足する場合は縦スクロール。情報を勝手に省略しない。印刷A4縦横と個別座席間隔も対応。
- alert13か所・confirm6か所を共通の中央専用dialogへ。背景操作抑止、フォーカス復帰、確認Escキャンセル、背景クリックで閉じない、二重実行防止。既存の高度な確認と画面内通知は保持。非同期確認後の履歴選択・読込・再読込順を維持する。
- 試作通常/サンプルの保存領域・画面設定・削除対象を分離し、既存版の削除正規表現にも一致させない。旧通常版を自動読込しない。既存バックアップは明示取込で6×7として受入。試作出力は専用識別子とファイル名にし既存版へ誤取込されないようにする。
- サンプルは既存サンプルを読取専用で利用し再読込でリセット。通常モードとの保存分離を守る。試作版へのリンクと試作表示を用意するが既存版への導線を誤操作させない。

方式比較: 既存版直接変更は試作分離要件に合わない。共通化リファクタは本番変更と影響範囲を増やすため、試作ディレクトリへの複製を採用。常時全体縮小より可読性優先、異寸法でも座標で同席評価する方式より同寸法のみ評価する方式を採用。
